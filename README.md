# حمودي الجميل 🌱

لعبة HTML عربية تفاعلية موجّهة للأطفال بعمر 4 سنوات، بأربع حدائق تعليمية: الألوان، العد من 1 إلى 5، مطابقة الأشكال، ومطابقة الحيوانات.

## التشغيل
نزّل ملف index.html وافتحه في متصفح حديث. لا يحتاج إلى تثبيت أو مكتبات أو اتصال بالإنترنت للعب والنغمات. لا يعني رفع المشروع إلى GitHub نشر موقع عام؛ المستودع خاص حاليًا، ولم يتم تفعيل GitHub Pages.

## التصميم
- واجهة RTL متجاوبة وأزرار لمس كبيرة.
- شخصية حمودي مرسومة بـ SVG داخل الملف.
- خمس أسئلة في الجولة، وترتيب عشوائي للاختيارات.
- تشجيع دون مؤقّت أو عقوبات، مع حفظ النجوم محليًا.
- نغمات مولّدة باستخدام Web Audio وزر كتم.
- قراءة اختيارية للسؤال عند توفر صوت عربي في المتصفح؛ قد يعتمد النطق على خدمات الجهاز الخارجية.
- احترام تفضيل تقليل الحركة ودعم التنقل بلوحة المفاتيح.

## الخصوصية
لا تحليلات ولا إعلانات ولا حسابات أو مكتبات أو صور خارجية. النجوم وإعداد الصوت محفوظة في localStorage على الجهاز، ويمكن تصفيرها من ركن الأهل. قد لا يستمر التخزين في التصفح الخاص أو عند حظره. لتجنّب النطق الخارجي اترك الصوت مكتومًا أو لا تستخدم زر قراءة السؤال.

## ملاحظات
الألوان نشاط للتعرّف على اللون بالاسم، ويفيد أن يقرأ أحد الأهل السؤال عند عدم توفر صوت عربي. قد يختلف مظهر الإيموجي حسب النظام. لا توجد تسجيلات بشرية مضمّنة. لا يدّعي المشروع تقييم مستوى الطفل أو كونه منهجًا تعليميًا معتمدًا.

## حالة الاختبار
لم يُختبر هذا الإصدار داخل متصفح فعلي أثناء إنشائه. قبل إتاحته للطفل، جرّب الأنشطة الأربعة، الإجابة الصحيحة وإعادة المحاولة، كتم الصوت، حفظ النجوم بعد إعادة الفتح، والتخطيط على الهاتف.
